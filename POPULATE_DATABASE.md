# Заполнение базы данных услугами

Чтобы заполнить базу данных всеми 49 услугами, выполните POST запрос к API endpoint:

## Способ 1: Через браузер (консоль разработчика)

1. Откройте сайт в браузере
2. Откройте консоль разработчика (F12)
3. Выполните следующий код:

```javascript
fetch('/api/populate-services', { method: 'POST' })
  .then(r => r.json())
  .then(data => console.log(data));
```

## Способ 2: Через curl

```bash
curl -X POST https://your-domain.com/api/populate-services
```

## Что делает этот endpoint

- Удаляет все существующие услуги из базы данных
- Добавляет 49 услуг с подробными описаниями, распределенных по 7 категориям:
  - Замена основных жидкостей (6 услуг)
  - Замена фильтров (4 услуги)
  - Зажигание, привода и топливо (7 услуг)
  - Тормозная система (7 услуг)
  - Рулевой механизм (7 услуг)
  - Подвеска (12 услуг)
  - Кондиционер (6 услуг)

После успешного выполнения все услуги появятся:
- На странице `/services` с карточками услуг
- В калькуляторе `/calculator` для расчета стоимости

## Структура услуги

Каждая услуга содержит:
- Название (name_ru)
- Подробное описание (description_ru)
- Цену от (price_from)
- Категорию (category)
- Порядок сортировки (sort_order)
- Статус активности (is_active)
