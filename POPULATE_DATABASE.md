# Заполнение базы данных услугами

Чтобы заполнить базу данных всеми 49 услугами, используйте один из следующих способов:

## Рекомендуемый способ: Через браузер

1. Откройте сайт в браузере
2. Откройте консоль разработчика (F12)
3. Выполните следующий код:

```javascript
fetch('/api/populate-services', { method: 'POST' })
  .then(r => r.json())
  .then(data => console.log(data));
```

## Альтернативный способ: Через curl

```bash
curl -X POST https://motorexpert.ru/api/populate-services
```

Или на локальном сервере:

```bash
curl -X POST http://localhost:3000/api/populate-services
```

## Что делает этот endpoint

- Удаляет все существующие услуги из базы данных
- Добавляет 49 услуг с подробными описаниями, распределенных по 7 категориям:
  - Замена основных жидкостей (6 услуг)
  - Замена фильтров (4 услуги)
  - Зажигание, привода и топливо (7 услуг)
  - Тормозная система (7 услуг)
  - Рулевой механизм (7 услуг)
  - Подвеска (12 услуг)
  - Кондиционер (6 услуг)

После успешного выполнения все услуги появятся:
- На странице `/services` с карточками услуг
- В калькуляторе `/calculator` для расчета стоимости

## Как это работает

Когда вы откроете страницу `/services`, она загрузит все услуги из базы данных и отобразит их в виде карточек, сгруппированных по категориям.

Каждая карточка содержит:
- Название услуги
- Подробное описание
- Цену
- Две кнопки:
  - **"Рассчитать стоимость"** - ведет на страницу калькулятора
  - **"Записаться на ремонт"** - ведет на страницу контактов

## Структура услуги в базе данных

Каждая услуга содержит:
- **name_ru** - название услуги на русском
- **description_ru** - подробное описание услуги
- **price_from** - начальная цена (в рублях)
- **category** - категория услуги
- **sort_order** - порядок отображения
- **is_active** - активна ли услуга (true/false)

## Проверка результата

После заполнения базы данных:
1. Перейдите на страницу `/services`
2. Вы увидите все 49 услуг, разбитые на 7 категорий
3. Калькулятор `/calculator` автоматически загрузит все услуги
4. Каждая карточка будет содержать описание и две кнопки действий
